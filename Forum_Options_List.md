# StripTease - Complete Options & Features List

Here is a concise overview of all the customizable options and menus available in StripTease, organized by element type.

## 1. Global Panel Options (Background Menu)
*   **Add elements:** Knob, Toggle, Radio, GR meter, GR bar (Horizontal/Vertical), Separator, Title.
*   **Edit mode:** Enable drag to move and `Shift + drag` to resize elements.
*   **Display:** Globally show/hide element names and knob value rings.
*   **Scroll groups:** Link panels to scroll together across tracks (Independent, Group A, B, C, D).
*   **Color:** Choose panel background from 11 presets or a custom RGB Palette.
*   **Layout grid:** Set 1 to 4 columns, or auto-fit grid to the largest element.
*   **Tabs (Pages):** Split the panel into 2, 3, or 4 pages (or turn Off).
*   **Clipboard:** Copy/Paste entire panel layout & links, or just a selection of elements.
*   **Preset links:** View link status, force-capture links, or forget preset links.
*   **Reset:** Reset all controls to default, resend all CCs, or clear the entire panel.

## 2. Knobs, Toggles & Radios
*   **Rename:** Set a custom label.
*   **Rename (ON):** Set a specific label for the engaged state *(Toggles only)*.
*   **MIDI Routing:** Assign CC number (0-127) and MIDI channel (1-16 or All).
*   **Color:** Choose from 11 presets or a custom RGB Palette.
*   **Size:** Pick from 6 presets (Tiny to Huge) or manually resize.
*   **Positions:** Set 2 to 6 steps *(Radios only)*.
*   **Orientation:** Switch between horizontal and vertical layout *(Radios only)*.
*   **Behavior:** 
    *   **Momentary:** Switch stays on only while held *(Toggles only)*.
    *   **Bipolar / Init at max:** Change default resting position *(Knobs only)*.
*   **Direct Link:** Learn, Re-learn, or Clear direct plugin parameter links.
*   **Tab routing:** Move the element to another tab page.
*   **Management:** Edit mode, Duplicate, Delete.

## 3. GR Meters (Needle VU)
*   **Rename:** Set a custom label.
*   **Measure Mode:** Choose between Gain reduction, Input level, or Output level.
*   **Reference:** Set 0 VU to 0, -9, -12, -14, -18, or -20 dBFS *(Level modes only)*.
*   **Source:** Read from Compressor 1, 2, or Gate 1 on the track *(Gain reduction mode only)*.
*   **Scale:** Choose Linear or Exponential dial scale.
*   **Color & Size:** 11 color presets + Palette, 6 size presets + manual resize.
*   **Display:** Show numeric dB value, enable Peak hold.
*   **Calibration:** Manual trim screw to offset the reading by ±6 dB.
*   **Management:** Tab routing, Edit mode, Duplicate, Delete.

## 4. GR Bars (Horizontal / Vertical)
*   **Rename:** Set a custom label.
*   **Source:** Read from Compressor 1, 2, or Gate 1.
*   **Orientation:** Switch between Vertical and Horizontal display.
*   **Scale:** Choose Linear or Exponential scale.
*   **Color & Size:** 11 color presets + Palette, 6 size presets + manual resize.
*   **Display:** Enable Peak hold.
*   **Management:** Tab routing, Edit mode, Duplicate, Delete.

## 5. Titles & Separators
*   **Rename:** Set a custom text label *(Titles only)*.
*   **Color:** Choose from 11 presets or a custom RGB Palette.
*   **Management:** Tab routing, Edit mode, Duplicate, Delete.

## 6. Tabs Menu (Right-click on a Tab)
*   **Rename tab:** Set a custom name (up to 12 characters).
*   **Reset tab name:** Revert to the default page number.
*   **Tabs...:** Change the total number of pages directly from the tab row.
